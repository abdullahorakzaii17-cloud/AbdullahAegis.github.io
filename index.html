🌐 Networking & Protocols

OSI Model & Layers Layer 1-7

Core architecture framework defining how data moves across communication networks from physical media to applications.

Basic: 7 layers divided into Media (1-3) and Host layers (4-7).

Advanced: Encapsulation/Decapsulation mechanics, TCP/IP mapping, and deep packet inspection points at Layer 4 (Transport) and Layer 7 (Application).

TCP vs UDP & Sockets Transport

Understanding connection-oriented reliable transmission versus connectionless datagram streaming performance.

Basic: TCP ensures delivery with 3-way handshakes; UDP is faster for real-time video/gaming.

Advanced: Socket programming states (LISTEN, ESTABLISHED, TIME_WAIT) and window scaling optimizations.

Subnetting & CIDR Addressing

Dividing large IP networks into smaller, manageable subnet masks for optimal routing and security compartmentalization.

Basic: Calculating host ranges using CIDR blocks like /24 or /28.

Advanced: Variable Length Subnet Masking (VLSM) and route summarization architectures.

Process & Resource Management SysAdmin

Monitor, trace, and terminate running system processes and evaluate CPU/memory usage dynamically.

Basic: Use ps aux, top, and kill [PID].

Advanced: Trace system calls using strace -p [PID], analyze performance bottlenecks with htop, and manage process niceness with renice.

Permissions & ACLs Security

Master Linux file security controls, UID/GID mapping, SUID/SGID bits, and Access Control Lists.

Basic: Standard chmod 755 and chown ownership rules.

Advanced: Auditing SUID binaries for privilege escalation vectors and setting granular permissions using setfacl / getfacl.

Network Troubleshooting Diagnostics

Inspect active socket connections, packet paths, and interface configurations in real-time.

Basic: ip a, ping, and netstat -tuln.

Advanced: Modern replacements like ss -tulpn, traffic capturing via tcpdump -i eth0, and network tracing with traceroute.
