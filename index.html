Network Fundamentals OSI & TCP/IP

Core architecture framework defining how data moves across communication networks, encapsulation, and cabling standards.

Exam Core: OSI 7-Layer model vs. TCP/IP 4-Layer model mapping.

Deep Dive: Encapsulation/Decapsulation mechanics, Data Link layer addressing (MAC/EUI-48), physical layer media types (Copper UTP, Fiber SMF/MMF), PoE (Power over Ethernet 802.3af/at), and collision/broadcast domain boundaries.

LAN Switching Technologies VLANs & STP

Layer 2 switching operations, Virtual LAN segmentation, trunking protocols, and loop prevention mechanisms.

Exam Core: Access vs. Trunk ports, IEEE 802.1Q encapsulation, and Native VLAN configuration.

Deep Dive: Spanning Tree Protocol (STP / RSTP 802.1w) port states (Discarding, Learning, Forwarding), BPDU guard, PortFast, Inter-VLAN routing (Router-on-a-Stick & Layer 3 Switches), and EtherChannel (LACP/PAgP).

Routing Technologies & OSPF Layer 3

Static routing configurations and dynamic interior gateway routing protocols for multi-hop packet delivery.

Exam Core: Administrative Distance (AD), Metric calculation, and floating static routes.

Deep Dive: OSPFv2 (Single-Area & Multi-Area Open Shortest Path First). Link-State Advertisements (LSAs), Dijkstra's Shortest Path First (SPF) algorithm, router IDs, Hello timers, and passive interfaces.

IPv4 & IPv6 Addressing Subnetting

IP network design, variable-length subnet masking (VLSM), public vs. private spaces, and next-gen addressing.

Exam Core: CIDR notation, subnet calculation, wildcard masking, and address allocation.

Deep Dive: IPv6 global unicast, link-local, unique local addresses, SLAAC (Stateless Address Autoconfiguration), EUI-64 format, and dual-stack migration strategies.

IP Services & Infrastructure DHCP, NAT, ACL
