Networking Field Notes

Core networking architecture study guide compiled from hands-on lab experiments.

1. Critical Ports & Services

  • SSH (Port 22) — Secure encrypted shell connection for remote administrative management.
  • DNS (Port 53) — Domain Name System protocol resolving human-readable names to IP addresses.
  • HTTP / HTTPS (80 / 443) — Web data transfer protocols (unencrypted vs TLS/SSL secured).

2. Diagnostic Commands

  • ping <host> — Verify host reachability and round-trip latency via ICMP echo requests.
  • traceroute <host> — Map out network gateway hops across the end-to-end path.

Linux Command Journal

Terminal fluency and system operations reference sheet for administrative security tasks.

1. File Permissions & Control

  • chmod 755 script.sh — Assigns read/write/execute rights to owner, and read/execute to group/others.
  • chown user:group file — Alters file user ownership and group association.

2. Process Monitoring

  • ps aux | grep service — Filters active process list for specific daemon keywords.
  • kill -9 <PID> — Forcefully terminates a misbehaving process identifier.

Python Utilities & Snippets

Python script references designed for automated reconnaissance and task execution.

1. TCP Socket Connection Test

Quick socket check snippet to determine if a specific target port is accepting traffic:

import socket

target_ip = '127.0.0.1'
target_port = 80

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.settimeout(2)
result = s.connect_ex((target_ip, target_port))
if result == 0:
    print(f"Port {target_port} is OPEN")
else:
    print(f"Port {target_port} is CLOSED")
s.close()
