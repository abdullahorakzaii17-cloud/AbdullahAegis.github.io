# AegisCore website

A responsive one-page cybersecurity learning portfolio.

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html` to the repository root and commit the change.
4. Open `https://YOUR-USERNAME.github.io` after GitHub Pages finishes publishing.

Alternatively, create a repository with any name, then go to Settings → Pages and select deployment from the `main` branch and `/ (root)`.

## Personalize
- Replace the generic project descriptions with your completed work.
- Add your own GitHub profile URL to the button near the bottom.
- Do not publish your phone number, home address, passwords, or private information.
- Keep claims honest: list only skills and certifications you actually have.
